    GOOD TO KNOW

    下载之前，了解这几件事

    为什么连接或下载失败？

    你的 Alist 必须允许本站来源访问 API；文件直链所在的存储服务也需要允许跨域。HTTPS 页面通常无法连接 HTTP 服务。网络、权限、过期签名链接或防盗链规则也可能阻止下载。本工具不会使用代理绕过这些限制。

    哪些浏览器支持直接存文件夹？

    需要安全环境（HTTPS 或 localhost）和 File System Access API。支持情况以页面检测为准；部分 Chromium 浏览器支持，Firefox、Safari 和部分移动端通常不支持。不可用时仍可尝试 ZIP。目录模式遇到同名文件会自动重命名，不默认覆盖。

    大文件与暂停有什么限制？

    支持保存文件选择器时，ZIP 可直接写入磁盘；否则 ZIP 使用内存打包，限制 256 MiB 和 10,000 个文件。暂停是当前页面内的协作式暂停，不等于断点续传。取消或关闭页面后无法跨会话恢复；重试会从文件开头重新下载。空目录不会单独下载。

    我的账号和文件安全吗？

    本站没有后端，不保存账号、密码或 Token，也没有分析追踪。凭据仅用于当前页面与所填写 Alist 站点通信；文件直接从其存储源获取。断开连接或刷新会清除内存状态。请只连接你信任且有权访问的站点；浏览器自身可能保留输入或下载记录。
